# Zyntra — Post-Break Physiological Readiness Clearance System

> **CS3283 — Embedded Systems Project | Semester 5 | University of Moratuwa**
>
> **Zyntra** is an ESP32-based wristband that monitors three independent physiological signals during a rest break and issues a verified **READY / NOT READY** clearance before a worker returns to a dangerous task — replacing guesswork with data.
